# MyRep - 学习笔记与资源仓库

该仓库记录了一些作者的课堂学习以及课外学习笔记，同时还顺便放了一些学习资料，未来可能还会放点作业上去。

## 📂 仓库内容

- **数学相关** - 数学课程笔记和资料
- **计算机科学相关** - 编程学习笔记（Git、Linux、Python等）
- **其它** - 其他学习资源和工具

## 🐧 NixOS 配置

**新增！** 为数学与统计学专业学生定制的 NixOS 系统配置，特点：

- ⚡ **高效续航**：TLP 电源管理，智能 CPU 调频，优化电池寿命
- 📊 **数学统计工具**：Python (NumPy/SciPy/Pandas)、R/RStudio、LaTeX、Jupyter
- 💻 **开发环境**：C (GCC/GDB/CMake)、Python 3.11、VSCode、Neovim
- 🇨🇳 **中文支持**：完整中文环境、Fcitx5 输入法、中文字体
- 🎨 **现代桌面**：GNOME 桌面（可选 XFCE 轻量版）

### 快速开始

```bash
# 克隆配置
git clone https://github.com/apple-pear-greap/MyRep.git
cd MyRep/nixos-config

# 查看文档
cat README.md        # 完整文档
cat QUICKSTART.md    # 快速开始指南
cat EXAMPLES.md      # 配置示例
```

详细说明请查看 [nixos-config/README.md](nixos-config/README.md)。
